## 新增音频怎么生成
在 GitHub → Actions 里运行 Phrase audio 工作流:会补齐句子(三种声音)、儿童词、例句、查词单词、句型、连读的缺失音频(已存在的跳过)。跑完会推一个 audio/phrases-<编号> 分支,告诉我,我来开 PR。
