# 检查清单(Claude 验收时使用)

每个任务从"待检查"改成"已通过"前,逐项核对。

## 通用
- [ ] `npm ci && npm test && npm run build` 全部通过
- [ ] e2e(`tests/e2e/run.py`)通过,没有为了让测试通过而删除或放宽原有检查
- [ ] CHANGELOG 有对应记录;DECISIONS 记录了新的取舍、依赖和许可证
- [ ] 没有提交密钥、大文件、`node_modules`、`dist`
- [ ] 没有改动 PRODUCT.md 的范围和验收标准
- [ ] 提交是一个任务一个提交,信息清楚

## 数据安全
- [ ] 改了 IndexedDB 结构的:数据库版本已升级,有迁移,旧数据不丢
- [ ] 改了备份格式的:版本号已升级,旧备份仍可导入
- [ ] 刷新页面、退出重开后进度还在

## 小白体验
- [ ] 手机尺寸(393×852)下没有溢出、按钮够大
- [ ] 界面全是简体中文,没有英文菜单
- [ ] 断网可用(V1 要求)
- [ ] 国行手机没有谷歌服务时发音仍可用(内置音频优先)

## 内容质量
- [ ] 抽查 30 个词的音标、释义是否合理(尤其是前 100 个)
- [ ] 例句简单、自然、无语法错误
- [ ] 音频文件名与单词完全一致,能播放

## 常见漏洞
- [ ] 时区与日期边界(凌晨学习、跨天)
- [ ] 空状态(没有待复习、今天新词学完、词库学完)
- [ ] 反复点击、快速连点评分按钮不会重复记录
- [ ] 导入损坏的备份文件会给出提示,不会清空现有进度
